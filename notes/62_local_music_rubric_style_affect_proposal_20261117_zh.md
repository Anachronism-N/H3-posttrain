# 局部音乐编舞评测：D4–D6 风格与情绪适配候选方案

日期：2026-11-17。状态：待校准的设计提案，尚未成为正式评分协议。

本次只提交文档，不修改评测程序、论文量表或已有分数，不启动训练与集群推理。

## 1. 本轮建议

短窗口内不一定出现明显转折、重音或休止。D6 不再以这些事件的存在作为必要条件，也不延伸到长程编舞。

建议保留 D4、D5 的核心目标，将 D6 候选定义为：

> **音乐情绪与动作表达相容性**：当前片段中，文字动作体现的表现意图，能否对实际音乐气质形成合理诠释。

具体舞种与音乐类型的匹配作为辅助判断，不以标签是否相等作为质量分。新 D6 的覆盖和区分能力仍须实测。

## 2. 维度分工

| 维度 | 判断对象 | 核心问题 |
|---|---|---|
| D4：节律适配 | 速度、重复、持续、节奏细分与音乐脉冲的关系 | 动作按什么节奏进行？ |
| D5：动力学适配 | 力度、幅度、发力与释放、流畅与顿挫 | 动作怎样完成？ |
| D6：情绪与动作表达相容性 | 姿态、手势和动作语汇体现的表现意图 | 动作呈现何种气质，与音乐是否相容？ |

L1–L3 继续负责跨窗口及整曲组织。D6 的观察范围严格限定在当前片段。

D6 不主要依据快慢、能量和幅度，否则会重复 D4/D5。它关注俏皮、庄重、克制、开放、内省等表现意图，但不要求出现这些词。只从身体动作判断，不要求面部表情、服装或场景描述。

以下为说明性例子，不是实验结果：同样轻缓、受控的侧踏，配合身体展开和邀请式前伸，可以支持开放的表现；配合身体收拢、双臂靠近躯干和缓慢后撤，可以支持克制或内省的表现。不能把任一动作固定归为唯一情绪。

## 3. 严格评分锚点

### D4 与 D5

| 分数 | D4：节律适配 | D5：动力学适配 |
|---|---|---|
| 1 | 核心节律主张与可听脉冲、停顿明确冲突，或无法形成可识别的动作时序 | 主要对应依赖虚构的音乐事实，或核心动力学关系明确矛盾 |
| 2 | 有动作顺序，但音乐时序关系未落实，主要依靠泛化说明 | 有动作，但动力学属性不足或主要是通用修饰 |
| 3 | 动作节奏可识别且总体兼容，具体音乐依据较弱 | 动作质感具体且总体兼容，与当前音乐的关系有限 |
| 4 | 重要动作时序有具体音乐依据，仅有少量非关键遗漏 | 发力、幅度或延续方式有具体音乐依据，仅有少量非关键遗漏 |
| 5 | 主要节律选择得到具体音乐证据支持，整体连贯且无关键矛盾 | 主要动力学安排连贯，发力、幅度和延续方式得到实际声音特征支持 |

不得用动作数、字数、关节数或动作数/拍数的固定区间替代质量判断。合理的半速、持续、静止及反衬均可高分。

### 新 D6 候选

| 分数 | 判据 |
|---|---|
| 1 | 对音乐气质的关键判断明显失实，使主要动作表达关系难以成立；须指出具体矛盾 |
| 2 | 有动作，但表现意图未落实；主要依靠“欢快、优美”等泛化修饰 |
| 3 | 动作体现可识别的表达，与音乐总体相容，但联系较弱 |
| 4 | 音乐依据、表现意图和具体动作之间关系清楚，只有少量遗漏 |
| 5 | 具体动作构成连贯、有辨识度的音乐诠释，并得到实际听觉证据支持 |

必须区分：

- **信息不足**：只有部位和方向，难以判断表现意图。
- **明确不相容**：音乐证据与候选主要表达之间存在可说明的冲突。

前者不能被编造成后者。纯中性描述不自动满分，也不自动被认定表达了错误情绪。高分不要求情绪词或舞种术语；只有标签而没有动作证据不足以高分。

## 4. 风格、情绪与 JEV 的边界

同一种音乐可以支持不同舞种与编舞解释。不能制定音乐类型与舞种的唯一映射。五秒内无法可靠识别的细分类型，不得补猜。

主 D6 判断动作正文的表现相容性。具体舞种兼容性可以作为辅助记录，不额外加入未经校准的加权总分。

所有方法采用相同的评审预处理：保留动作正文，遮蔽 `Dance style is ...` 等风格头、生成模型名称及额外的自我评价。

- JEV 可以提供生成条件，其分类实验仍按独立分类协议报告。
- D6 不使用生成时采用的 JEV 预测作为正确答案。
- 只替换风格或情绪标签而不改变动作，不应提高 D6。
- 用户明确指定舞种时，可另评指令遵循；这不是音乐适配的同一个问题。

允许有音乐依据的反衬。悲伤音乐与轻快动作并非必然不相容，但一句“故意形成反差”不足以获得高分。

## 5. 评审证据与不确定性

1. **独立听音**：不看候选，记录片段可支持的音乐气质、兼容解释及不确定性。评价音乐呈现的情绪，不评价评审的喜好或被诱发的感受；不凭歌名或整曲先验补信息。
2. **读取动作正文**：引用原句中的动作语汇、姿态或手势选择，说明其支持的表现意图。不得补出文本没有提供的动作、表情或动力学。
3. **建立关系**：给出听觉证据、动作证据及二者为何相容或不相容。评审仍接收原始音频，观察摘要不能替代听音。
4. **逐维验收**：D4/D5/D6 分别评分与校验。一维格式失败不自动丢弃其他合法评分；保留原始响应与错误类型。

新 D6 不沿用旧协议“必须有明显音乐发展事件”的门槛。没有转折不等于无法评价气质。

音频气质本身难以确定时保留 Unknown；音频缺失、服务失败与解析失败分别记录。音频观察的不确定性对所有方法一致冻结，不强行把所有片段分为快乐或悲伤。音频证据充分而候选表达空泛时，应记内容不足，不能用 Unknown 回避。

该评分评价文字计划，不等于真实舞者的情绪表达效果、观众感受或已经实现的动作同步。

## 6. 校准与防刷分控制

| 控制 | 预期行为 |
|---|---|
| 只增加风格或情绪标签，动作正文不变 | 不因标签自动涨分 |
| 同义改写或拆分相同动作描述 | 分数应基本稳定 |
| 保持速度和力度相近，改变手势与姿态的表现方向 | D6 应有机会区分，D4/D5 不应机械同步变化 |
| 只改变速度，保持表现意图 | 主要检验 D4，不把速度直接当作情绪 |
| 只改变动力学，保持时序与表现意图 | 主要检验 D5，跨维影响须有独立理由 |
| 虚构音乐气质并据此安排动作 | 有确切矛盾时降低 D6 |
| 同一文字配两段同样兼容的音乐 | 不强制分出唯一正确音乐，允许平局 |
| 有依据的半速、持续或反衬 | 不因简单、缓慢或不同向表达自动扣分 |

开发素材应包含稳定音乐与情绪模糊片段，不能只选转折明显或有利于某方法的样本。先由两名独立听评者检查这些控制，再冻结规则与评审配置。

新 D6 需通过两个关键检验：它能否识别动作表达差异，而非风格头或形容词；它能否提供超出 D4/D5 的信息。如果理由仍主要是快慢、力度或能量，就不应作为独立维度。

## 7. 实施与版本管理

- 先用 24–40 段开发素材校准，再用未参与规则修改的正式素材评测所有方法。
- 原始 SFT、完整推理流程和通用模型共用评审配置，匿名比较；可辅以双顺序成对评审及人工一致性检查。
- 资源为现有音频评审模型、保存的候选文本及人工校准；不需要为该候选量表新增训练。
- 新协议另建版本和运行目录。旧事件型 D6 不能直接重命名为新 D6，旧分数不能与新量表结果混用。
- 既有 D1–D3 及旧音乐评测记录继续冻结保存。本提案不自动改变论文数值，不证明当前方法已经改善。
- 校准后再同步提示、维度定义、状态字段、逐维校验、统计汇总、论文量表及图示，不能只替换 prompt 名称。
