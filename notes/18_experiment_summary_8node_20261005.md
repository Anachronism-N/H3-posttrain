对应计划：`notes/17_experiment_plan_8node_h20_20260930.md`。逐条数据与过程记录：`logs_omnidance/exp/RESULTS.md`。
所有数字均为 OD-Val-47（47 条验证样本）上的结果，评测协议见第 2 节。

## 0. 一页结论

1. **底座 S4-final 已完成**（E1）：joint TextAlign 0.659 → 0.725，运动幅度 +19%，身份不变。
2. **核心问题被重新定义**（E2/E3/E10）：不是"模型只听音乐"，而是**文本控制不了动作**。换掉 prompt 后动作基本不变（Δtext ≈ 0）。一个主要原因是原 caption 本身不描述具体动作。
3. **不换底座**（E3，G1 不通过）：H3 零样本在动作可控性上也不显著（Δtext +0.025±0.037），而且换文本会直接丢掉参考图身份。
4. **4 步学生两条都打通了**：
   - 双向 DMD（E5）：704p 稳定，480p 必崩；最好的 b5@3000 身份 0.855、TA 为老师的 96%。
   - **AR 流式学生**（E6，直接做 AR 而不是先蒸双向）：因果 ODE 回归 → Self-Forcing DMD，身份 0.857（老师 0.845），TA 0.68（老师 0.725），每块 4 步、无 CFG，前向次数约为老师的 1/35。
5. **长视频**（E9）：续写式 SFT 把接缝跳变比从 1.46 降到 1.12，末段颜色漂移从 4.16 降到 3.74。
6. **RL（E7）的自蒸馏路线失败**：3 个版本都没有让 Δtext 变正，且每轮动作幅度下降 20–25%；原因是随机 4 步采样器上的回归目标本质上是均值。该路线已停止。
7. **音乐 reward 已修好**（G2 音乐部分通过）：节拍类指标无效（AUC 0.4–0.6），新训练的音乐–动作对比判别器在 GT 上 AUC 0.906。
8. **判别器揭示：音乐同样不控制动作**。换音乐后，生成的动作仍更像配原音乐（Δaudio_disc = −0.08，S4-final 与 H3 都如此）；不给音乐时动作也与原音乐相关。动作主要由参考图和原 caption 决定——这才是真正要解决的"条件可控性"问题。
9. **AR 学生 + 参考图 sink 可以生成 33 秒长视频**，接缝与 50 步老师续写（E9a）持平，耗时约 1/4。
10. **E10-stage5（36k 动作 caption + 2000 步 SFT）没有让文本控制动作**（Δtext +0.016±0.033），CFG 加到 5/8 也只到 +0.03~0.04 且身份明显下降。
11. **根因诊断**：在我们的模型里，只换噪声种子对动作的改变（0.22–0.29）≥ 换文本（0.19–0.25）≫ 换音乐（0.05–0.07）；不给文本、换音乐后动作仍更贴合原音乐。动作主要由参考图（原视频首帧）+ 噪声决定，条件几乎不起作用。H3 对音乐的响应是我们的 3 倍。

## 2. 评测协议（E2/E4）

- 5 种条件：joint / audio_only / text_only / tswap（换成别的样本的 prompt）/ aswap（换音乐）。
- 指标：TextAlign（Qwen3-VL-8B，按 prompt 子句逐句问 P(Yes)，8 帧）、身份（DINOv2 与参考图余弦）、运动幅度、首帧 PSNR、Pose-BAS 等节拍指标。
- **Δtext** = TA(tswap 视频, 新 prompt) − TA(tswap 视频, 原 prompt)：> 0 说明换了文本后动作确实向新文本靠拢。
- E10 之后，TextAlign 默认改用**动作 caption**打分（只描述身体动作，不含服装场景），否则换文本时外观变化会被误算成"跟文本"。

**G2（reward 校准）结果**：GT 上"自己的 caption vs 别人的 caption"的 AUC，原 caption 0.648，动作 caption 0.704（门槛 0.8）；节拍类指标 0.4–0.6。**G2 不通过**。

### E10 动作导向 caption
- Qwen3-VL-8B 看 16 帧，生成 5–7 句只描述身体动作的 caption。GT 区分度 AUC 0.648 → 0.704。
- 已用于：E3/E7 的打分；E7 的训练 prompt；正在为 36k 训练片段生成（见第 5 节）。

### E7 RL（第一版：奖励加权自蒸馏 + 锚点门控）
- 每个 prompt 4 个分支（锚点 / 换种子 ×2 / 删一句动作描述），reward = TA(动作 caption) + 身份惩罚；只有超过锚点 margin 的分支参与，Gibbs 权重选赢家。

| 模型 | joint TA（动作 caption） | ID | 运动 | Δtext |
|---|---|---|---|---|
| 基线 E6-3b | 0.556 | 0.818 | 0.229 | −0.013±0.034 |
| r0（赢家 latent + 新噪声回归） | 0.384 | 0.596 | 0.110 | 训坏 |
| r0b（在赢家自己的采样轨迹上回归） | 0.559 | **0.840** | 0.172 | −0.069±0.033 |
- r0 失败原因：输入噪声不是产生赢家的那条，4 步学生只能回归均值，变糊。r0b 修正后不再退化。
| r1v2（对比 reward TA(自己)−TA(别人)，2 轮累计） | 0.540 | 0.821 | 0.138 | −0.105±0.028 |
- r0b/r1v2 都没有提升可控性，而且每轮运动幅度掉 20–25%。诊断表明 reward 并不偏好小动作（相关系数约 0），萎缩来自训练目标：AR 采样器每步重新加噪，早期步的输入对应的最终输出不唯一，回归它仍是回归均值。
- **结论：停止"回归到赢家样本"的自蒸馏路线。** 继续 RL 需改为确定性采样器上的加权回归，或真正的策略梯度（KVPO / Flow-GRPO 式似然比），并且需要比 AUC 0.70 更强的 reward。

## 5b. E11 设计与进度
- 数据事实：每个训练片段都是独立的 5.12 秒源视频（263k 条源各出 1 条，无片段外帧），所以"参考图"只能从片段内部其他时刻取。
- 布局（`scripts_omnidance/exp/e11/train_e11.py`）：latent 0 = 干净参考图（取自片段第 ref_lo..ref_hi 帧，可做缩放平移/翻转/颜色扰动），latent 1..21 = 完整 81 帧片段（含片段首帧，不再作为干净输入），整体 flow matching，损失算全部 21 个 latent。音频前补 4 帧复制，使音频窗口与新布局逐帧对齐。S4-final + LoRA r128，lr 1e-4，2500 iter，条件配比 joint 0.5 / audio 0.3 / text 0.2。
- 推理：参考图 = 测试样本首帧（与训练不同时刻），输出 81 帧（`e11/sample_e11.py`，50 步三分支 CFG）。
- 冒烟测试：零样本时第一帧与参考图的 L1 为 17.6（不再复制参考图），约 15 s/iter，35 GB/卡。
| run | 参考帧范围 | 增强 | prompt | 节点 | 作用 |
|---|---|---|---|---|---|
| E11a | 40–80 | 缩放平移 | 原 caption | N2 | 主实验 |
| E11b | 20–80 | + 翻转、颜色 | 原 caption | N3 | 更强解耦 |
| E11c | 40–80 | 缩放平移 | 意图 prompt（+动作 caption） | N5 | 解耦 + 动作文本 |
| E11d | 0（= 片段首帧） | 无 | 原 caption | N6 | **对照**：同布局但不解耦，区分"布局变化"与"解耦"的作用 |
| E11e | 20–80 | + 翻转、颜色 | 意图 prompt | N4 | 两个因素叠加 |
- 训练结束后自动评测（`e11/chain_e11.sh`）：意图 prompt 下 joint / tswap / aswap（seed 42）+ joint（seed 43），算 TA、身份、关键点和 G2 判别器分数。
- 判定标准：换音乐的姿态距离从 0.05–0.07 提到 ≥ 0.12，aswap 的 D(换入音乐) − D(原音乐) 显著为正，换文本距离明显超过换种子距离；身份 ≥ 0.80。E11d 若同样有效，则说明作用来自布局而非解耦。
