# 正式实验结果（可直接用于写作）

日期：2026-11-15。本文只汇总**已冻结、可复现**的结果，数字全部来自 `experiments/structured_dev_20261114/` 与 `artifacts/sr-dev/` 下的原始记录。所有判断都标注了强度，未验证的内容单列。

## 1. 设置

| 项目 | 内容 |
|---|---|
| 语料 | 本地全部 11 首（5 dev / 6 test），MOSS 候选 K=2 / 5.0625 秒窗，冻结不重采 |
| 外层模型 | Qwen3-VL-30B-A3B-Instruct，temperature 0，json mode |
| 预算 | 每首 `1+4U` 次调用、2M 输入 / 150k 输出 tokens、单次请求 300k 字符、单次输出 4096 |
| 基线 B | `workflow`：大纲 + 每块一次生成，程序校验并提交 |
| 方法 O | `music_structured` + 声学引导 + 保语汇复读重写（≤5 组，重叠 ∈[0.20, 0.80]） |
| 评审 | Qwen3-VL-8B，盲化、隐藏主题标签、动作文本不截断、A/B 换序各判一次 |

协议文件：`formal_protocol.json`（在首次派发前冻结为 11 首）。

## 2. 主结果：完成与成本

| 指标 | B | O |
|---|---:|---:|
| 整曲合法完成 | **6/11** | **11/11** |
| 平均调用次数 | 22.8 | 27.2（+19%） |
| 平均输入 tokens | 255k | 297k（+16%） |
| 平均输出 tokens | 7.1k | 5.9k（−17%） |

基线 5 次失败中，3 次为大纲/块输出打满 4096、1 次为事件时间表不合法、1 次为服务端错误（重试 2 次仍失败）。方法侧唯一一次服务端错误重试后完成。

**机制**：基线 194 次响应中有 **8 次打满 4096**（生成 12–15 KB 的重复 JSON），每次都会让该歌直接失败；方法 299 次响应**从未打满**（最大 1639）。这说明完成率差异来自"生成是否有界"，而不是模型能力。此结论是观察到的关联，未做因果实验。

## 3. 内容质量：样本内有效，留出集未复现

只有两臂都完成的 6 首可配对（10811、12099、1881、3856、4151、6789）：

| 范围 | n | 两序均值 | 95% CI | 胜负 | 换序偏好一致 |
|---|---:|---:|---|---|---|
| 全部配对 | 6 | +2.50 | [0.08, 3.92] | 5–1 | 6/6 |
| dev（样本内） | 4 | **+3.63** | [3.25, 4.00] | 4–0 | 4/4 |
| **test（留出）** | 2 | **+0.25** | [−3.50, 4.00] | 1–1 | 2/2 |

换用 30B 判官重判同一批：总体 +2.42 [0.00, 4.25]、5–1（与 8B 一致），但 dev +1.75、test +3.75——**分离方向完全翻转**。两个判官都显示"总体弱正向"，但分集结论随判官变化，不可作为结论。

因此：**不能声称内容质量整体更优**。dev 是全部调参所用样本；test 只有 2 首（因为基线在另 4 首 test 上失败），既不足以证明有效，也不足以证伪。

## 4. 有效性检查（都已做）

| 检查 | 结果 |
|---|---|
| 判官位置偏置 | 正序两判的位置投票 ≈ 平衡（23/22/3） |
| 零假设对（两臂文本完全相同） | 开发集 3 对、**留出集 7 对**均为**精确 0.0**（56 次维度投票：50 平、0 次判给第一位）；判官不会凭空造差异 |
| 文本截断混杂 | 已发现并修正：旧结果用 160 字符截断，基线文本更长被截更多；现统一 400 字符 |
| 展示顺序 | 事件倒序后偏好方向仍为正（dev +4.62），说明不是只看开头 |
| 第二判官族 | 四个方案全部失败：音频成对、音频绝对、文本成对（81% 投第二位）、文本绝对（8 对中 4 对同分，+0.5 [−1.0, 2.0]） |
| 判官规模 | 30B 判官总体 +2.42 [0.00, 4.25]、5–1，与 8B 的 +2.50 一致；但 dev/test 分离完全翻转（30B：dev +1.75、test +3.75）→ **分集结论不可靠，只能报总体方向** |

## 5. 可以写与不能写

**可以写**
1. 同等预算下完成率 **11/11 对 6/11**，成本仅高 19% 调用、16% 输入。
2. 失控复读是基线失败主因（8 次打满 vs 0 次），这是可审计的工程结论。
3. 逐字重复率下降（0.68 → 0.42–0.50）。
4. dev 上盲评显著（+3.63，4–0，换序 4/4 一致）。

**不能写**
1. 内容质量整体优于基线（test 未复现）。
2. 秒级音画对齐更好（客观指标显示无差异）。
3. 任一组件可叠加（先验、提示变奏均无效）。

## 5b. 扩展集：3 首全新留出歌曲
