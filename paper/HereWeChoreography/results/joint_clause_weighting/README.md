# Joint-aware clause reweighting evidence

Frozen public implementation and v3 delivery report. These support text-clause weighting, the lower-limb instantiation and effective-token normalization; they do not establish a causal ablation. Code defaults to weight 1.0; the v3 delivery configuration specifies 1.5. Token-offset fallback and the absent random-clause control are disclosed in the appendix. No per-coordinate pose loss or independently learned joint weights are claimed. See provenance.json for immutable paths and hashes.
